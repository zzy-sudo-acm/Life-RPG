# Life RPG · 人生成长手账

一个手机优先、纯本地的成长记录工具。把大目标拆成每天能完成的小行动，用经验、成就与时间线保存自己的进步。

## 日常使用

底部导航提供四个入口：

- **今日概览**：今日行动、快速添加、当前主线、成长统计、专注计时和每日一记。
- **目标旅程**：长期目标与子目标路线；从“添加下一步”创建的任务会自动关联目标，完成后推进进度。
- **成长足迹**：本周行动、可展开的 12 周日历，以及重要事件、目标、成就与日常复盘时间线。点击日历可回顾某一天。
- **成就馆**：查看已获得的成就、自动解锁进度，也可以保存生活中的专属成就。

点击首页的角色名称进入 **成长档案**，编辑身份、阶段、技能与属性；设置中保留存档导入、导出和重置。

界面采用森林绿与山路插画，手机使用底部导航和底部表单抽屉，桌面使用侧栏。支持安全区、键盘弹出时的表单滚动、焦点管理和减少动画偏好。

## 新增的小功能

- **专注一小步**：15 / 25 / 45 分钟，可暂停、继续、重置。运行中的计时保存截止时间，切换页面或刷新后继续计算；结束后提示休息。它不会自动完成任务。
- **今日一记**：每天一条可重复编辑的复盘，保存为成长足迹中的手动事件，随存档一起导出。
- **行动回顾**：按照本地日期统计完成记录，避免凌晨完成任务被算进前一天。
- **目标下一步**：从目标直接添加关联任务，并自动切换到对应的任务列表。

## 自动奖励

任务表单只需名称、分类与难度，截止日期、关联目标和备注放在“更多选项”。系统自动计算角色经验、属性、技能和目标进度。

| 难度 | 基础 EXP | 属性成长 | 技能经验 | 关联目标进度 |
| --- | ---: | ---: | ---: | ---: |
| 简单 | 10 | 0.25 | 3 | 5% |
| 中等 | 25 | 0.5 | 6 | 10% |
| 困难 | 50 | 1 | 12 | 20% |

关联目标时，角色 EXP 额外增加 20%。完成任务统一通过原子结算入口，防止重复获得奖励。挑战目标沿用旧版 Boss 数据，只调整呈现方式。

## 数据与兼容

成长数据继续保存在 IndexedDB `life-rpg`，存档结构仍为 `schemaVersion: 2`；原有 v1 到 v2 迁移、跨标签页同步与 JSON 导入导出保持兼容。界面偏好与专注计时保存在 localStorage，计时不属于导出的成长存档。

这是本地应用，**不提供跨设备云同步**。不同浏览器、访问地址或设备使用独立存档；更换设备前请在设置中导出备份。

## 运行

需要满足 Vite 8 要求的 Node.js 版本。

```powershell
cd frontend
npm install
npm run dev -- --host 0.0.0.0
```

电脑访问终端输出的 Local 地址；同一 Wi-Fi 下的手机访问对应 WLAN 的 Network 地址。Windows 防火墙需要允许该开发服务器的局域网访问。

## 检查

```powershell
cd frontend
npm run test
npm run typecheck
npm run lint
npm run build
```

生产文件输出到 `frontend/dist/`。使用 React 19、TypeScript、Vite、Tailwind CSS、HashRouter、IndexedDB 与 Lucide。页面按路由分包，首页插画使用约 111 KB 的 WebP。
