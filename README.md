# Life RPG

Life RPG 是一个纯本地、移动端优先的日常成长工具。

核心原则：**输入尽量像 Todo，反馈尽量像 RPG。** 用户平时只需要查看今日任务、点击完成并快速添加下一条；EXP、技能、属性和目标进度由系统自动结算。

## 页面结构

主导航只有三个入口：

- **今日**：角色等级 / EXP、快速添加、今日待办、主要目标、最近奖励。
- **目标**：长期目标、子目标、Boss 展示模式以及全部关联任务。
- **角色**：等级、总 EXP、当前阶段、技能、五维属性、成就和成长足迹。

数据导入、导出和重置收纳在次级 **设置** 页面，不占主导航。

## 日常任务

默认任务表单只有：

- 任务名称
- 分类 / 标签
- 可选截止日期
- 难度（默认中等）

关联目标和描述收纳在“更多选项”。角色 EXP、属性成长、技能经验和目标进度均为只读预览，不允许手动填写。

### 自动奖励规则

| 难度 | 基础 EXP | 属性成长 | 技能经验 | 关联目标进度 |
| --- | ---: | ---: | ---: | ---: |
| 简单 | 10 | 0.25 | 3 | 5% |
| 中等 | 25 | 0.5 | 6 | 10% |
| 困难 | 50 | 1 | 12 | 20% |

- 任务关联目标时，角色 EXP 额外增加 20%。
- 分类决定主要成长属性：运动偏健康，数学 / 学习 / 语言偏智力，设计 / 创作偏创造力，计算机 / 技术 / 科研偏技术力，其他分类偏执行力。
- 分类下优先选择第一个根技能自动获得技能经验。
- 完成任务后自动推进关联 Goal；Boss 只是 Goal 的展示模式，不再维护独立 HP / damage 数据。

## 成就与成长足迹

- 成就保留手动和自动两种解锁方式。
- 内置自动信号包括累计完成任务、完成长期目标、技能等级和连续完成天数。
- 成长足迹只记录目标完成、成就解锁、阶段变化和用户主动添加的重要事件。
- 普通任务完成不会逐条写入成长足迹。
- 装备系统已删除。

## 本地存档与兼容性

业务数据保存在 IndexedDB，界面偏好保存在 localStorage。当前存档结构为 `schemaVersion: 2`。

旧版 v1 存档会自动迁移：

- Boss 合并到关联 Goal，并换算为 `progress`；没有关联目标的 Boss 会创建对应 Goal。
- Boss damage 奖励换算为 Goal progress。
- 已发生的人生地图阶段合并到成长足迹；未来节点不写入历史。
- 普通任务完成事件会被过滤，避免成长足迹过于杂乱。
- 装备数据不再进入 v2 运行时模型。

导入页面同时支持 v1 和 v2 JSON 存档；浏览器内现有 v1 IndexedDB 会在首次打开新版时升级。

## 技术栈

- React 19 + TypeScript
- Vite 8
- Tailwind CSS 4
- React Router（HashRouter）
- IndexedDB（idb）
- Vitest + Testing Library + fake-indexeddb
- Lucide React

## 本地运行

```powershell
cd frontend
npm install
npm run dev
```

## 验证

```powershell
cd frontend
npm run test
npm run typecheck
npm run lint
npm run build
```

生产文件输出到 `frontend/dist/`。仓库内的 GitHub Pages 工作流会在 `main` 分支更新后完成测试和部署。
